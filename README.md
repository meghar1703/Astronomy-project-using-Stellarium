**Exploring Celestial Dynamics using Stellarium: A 50-Year Astronomical Analysis**

This project presents a comprehensive study of celestial object movements across constellations over a 50-year period using the planetarium software **Stellarium**. It combines astronomical simulation, data analysis, and visualization to uncover patterns in celestial motion and angular relationships between astronomical bodies.

---

### Key Features

* 🌌 Simulation of celestial motion using Stellarium
* 📊 Analysis of time taken by planets and the Moon to traverse constellations
* 📈 50-year dataset of astronomical positions (hour angle, declination, etc.)
* 📐 Calculation of angular separation between celestial objects
* 📉 Visualization of long-term patterns using Python (Matplotlib)

---

### Methodology

* Simulated celestial events using Stellarium
* Recorded entry and exit times of objects across constellations
* Generated ephemeris data for a 50-year span
* Calculated angular separations using Stellarium tools
* Processed and visualized data using Python

---

### Results & Insights

* Identified periodic patterns in angular separation between celestial bodies
* Observed varying transit durations across constellations for different planets
* Highlighted long-term cyclical behavior in celestial dynamics

---

### Tech Stack

* **Stellarium** (Astronomical simulation)
* **Python** (Data processing & visualization)
* **Matplotlib** (Graph plotting)
* **Excel** (Data logging & analysis)

---

### Applications

* Astronomy & Astrophysics research
* Educational visualization of celestial mechanics
* Astrology-based positional analysis
* Long-term astronomical pattern recognition
